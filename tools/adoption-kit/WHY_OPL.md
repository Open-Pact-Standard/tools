# Why OPL? (one page for decision-makers)

**Open-Pact License (OPL)** lets you use, modify, and share software freely for
**personal** purposes, and requires **payment to the Maintainer** when you use it
for **commercial** purposes. The Maintainer sets the price and the payment
mechanism. That's the whole model — free for individuals, paid for business.

## The one-sentence case
OPL captures the value of commercially-used software for its creator **without
forcing open-source publication** and **without a registry, token, or blockchain**.
If you want scheduled open-source conversion, you opt in (DOSP). If you don't, the
work stays source-available. Your choice.

## What it is NOT
- **Not OSI "open source."** OPL restricts commercial use unless you pay. That is
  intentional — it is a *fair-source* license, not an open-source license.
- **Not copyleft.** There is no GPL-style reciprocity or "infect" clause. (The old
  Functional Equivalent restriction was removed in v1.4.)
- **Not under any external registry or Fair Source org.** OPL is independently
  governed by the Open-Pact-Standard org (Ikaros Digital LLC). It is *aligned*
  with fair-source norms and converts to **Apache-2.0** on its triggers, so it is
  interoperable *if* you need that bridge — but it is its own standard.

## Why teams adopt it
| Concern | OPL answer |
|---|---|
| "We want to use it free internally for research" | Personal/non-revenue use is free, no gate. |
| "We'll pay if we monetize it" | Commercial Use requires payment per the Maintainer's published Standard Terms. You set nothing; they set the price. |
| "What if the project dies?" | Abandonment (Maintainer unreachable 36mo) auto-converts the work to Apache-2.0. No hostage risk. |
| "What if we want it to become open source later?" | Opt into DOSP in `NOTICE`; each Version converts to Apache-2.0 on schedule. |
| "Is the tooling real?" | See the worked example (origin-canary): 90 tests, theft + tamper detection. |

## The bottom line
OPL is a **creator-friendly, adopter-safe, zero-infrastructure** license. Free
for personal use, paid for commercial use, with an automatic Apache-2.0 escape
hatch if the Maintainer vanishes. No surprises, no chains.
